Same model, different harness: Factory's agent beat Claude Code by 7.6 points on Opus 5.5

Factory's own Terminal-Bench 4 runs show its Droid agent passing 65.2% of tasks versus 57.6% for Claude Code with the same model and settings, and finishing faster. Marketing Monk (sponsored)

Hostinger test: a wireframe image beat a typed prompt for AI-built landing pages

Marketing Monk built the same sign-up page three ways. A labeled wireframe gave the fastest, cheapest result with nothing to fix; a typed prompt needed fixes and invented a logo; cloning a live URL copied content faithfully but silently dropped the footer's privacy and legal links.

why it mattersTwo reusable patterns for her PMM workflows: give the model a structural reference instead of describing layout in words, and add a review step that checks for invented elements and dropped required content.

📊 Measuring AI Impact

Neatprompts (sponsored)

Factory Router reports 63% inference savings by sending routine work to cheaper models

Factory says routing each task to the cheapest model that can handle it cut aggregate inference cost 63% against frontier pricing in one September week, with median per-session savings of 72.5%. It measures cost per passed task, not per request.

Cost per successful output is a cleaner metric than token spend for her own workflow dashboards, and model routing is a lever worth testing on high-volume, low-stakes steps.
