The Code

Gumloop's 'software factory' shows how documented skills cut human rework on agent output

Gumloop routes work into lanes owned by one engineer each, lets an orchestrating worker read team skills and hand tasks to coding agents, and requires proof (such as a failing-then-passing test) with every change. Over five weeks it wrote or updated 94 skills, and the share of agent work merged with no human edits rose from 57% to 89%.

why it mattersThe pattern maps directly onto a PMM skills library: one owner per workflow, a 'receipt' requirement for every output, and no-human-edit rate as a quality metric worth tracking.

The IAB's AI-Era Attribution Blueprint sorts each sale into human-owned, AI-assisted or AI-executed by asking who created the intent, who decided and who completed the purchase. Google tests its agent anomaly detection against outside benchmarks

Google's Agent Anomaly Detection flagged 87% of harmful instructions that agents actually executed on third-party benchmarks. It did well on goal hijacking and tool misuse, struggled with poisoned memory, and had false-alarm rates up to 16% on tasks using high-impact tools.

Useful reference numbers when Security asks how agent misuse would be caught, and a reminder that agents with memory and write access need extra human review.
