How the Claude Code team makes agents verify their own work

Anthropic describes how Claude writes and reviews most of Claude Code: every agent gets automated checks it must pass, it can retry a failing check up to three times before handing off to a human, and it is never allowed to change the checks that judge it.

🛠️ try this

A self-check prompt for any PMM workflow

Add to one existing skill: 'Before drafting, tell me how you'll check this against [rubric]. After drafting, run the check and report results. If it fails, fix it up to three times, then stop and tell me. Don't change the rubric, and flag anything you couldn't check.' Compare how many edits you make versus last week.
